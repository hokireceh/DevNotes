Cara Install di Chrome

  1. Download folder chrome-extension/ dari project ini
  2. Buka Chrome, ketik chrome://extensions
  3. Aktifkan Developer Mode (toggle kanan atas)
  4. Klik tombol Load unpacked
  5. Pilih folder chrome-extension/
  6. Extension siap digunakan
